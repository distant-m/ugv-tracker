# tracker

Веб-застосунок з входом за обліковим записом. Код не містить даних: усі дані зберігаються в базі Supabase і доступні лише після входу, відповідно до ролі (адміністратор / користувач / глядач).

## Структура
- `app/` — сайт (публікується на GitHub Pages автоматично після кожного оновлення гілки `main`).
- `supabase/01_schema.sql` — таблиці, ролі, правила доступу, журнал змін.
- Початкове наповнення бази зберігається окремо, поза репозиторієм.

## Налаштування бази (один раз)
1. Supabase → SQL Editor → New query: вставити вміст `supabase/01_schema.sql` → Run.
2. Нова вкладка запиту: вставити файл початкового наповнення (надається окремо) → Run.
3. Authentication → Users → Invite user: запросити себе.
4. Після першого входу зробити себе адміністратором (SQL Editor):
   `update public.profiles set role = 'admin' where email = 'ВАША_ПОШТА';`
5. Storage → бакет `templates`: завантажити PDF-шаблони посадових обов'язків.

## Дата старту проєкту
Графік створено від умовної дати. Коли дата відома (SQL Editor):
`select public.set_project_start('РРРР-ММ-ДД');`
